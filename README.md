# Simple Interest Calculator

A lightweight script/tool designed to calculate simple interest quickly based on principal amount, annual rate of interest, and time period in years.

## 📌 Project Overview

Simple interest is a quick and easy method of calculating the interest charge on a loan or investment. This project provides a simple implementation to calculate both the interest earned/charged and the total amount payable.

### Formula Used

$$\text{Simple Interest (SI)} = \frac{P \times R \times T}{100}$$

$$\text{Total Amount} = P + \text{SI}$$

Where:
- **P** = Principal amount (Initial investment or loan amount)
- **R** = Annual interest rate (in percentage %)
- **T** = Time period (in years)

---

## 🚀 Features

- Input validation for principal, interest rate, and time duration.
- Calculates total interest and final total amount.
- Clean and easy-to-understand codebase.

---

## 💻 Usage & Example

### Example Calculation

If you invest **$1,000** at an annual interest rate of **5%** for **3 years**:

- **Principal ($P$):** $1,000
- **Rate ($R$):** 5%
- **Time ($T$):** 3 years

**Calculations:**
$$\text{SI} = \frac{1000 \times 5 \times 3}{100} = 150$$

$$\text{Total Amount} = 1000 + 150 = 1150$$

- **Total Interest Earned:** $150
- **Total Balance:** $1,150
